# VeppStatus Systemd Service

## Описание
Systemd сервис для автоматического запуска и поддержки работы VeppStatus (Django веб-сервер + сервер сбора данных). Автоматически определяет пользователя и пути на любой машине.

## Файлы
- `veppstatus.service` - файл systemd сервиса (базовый)
- `veppstatus_service.sh` - скрипт запуска для systemd
- `install_service.sh` - скрипт установки сервиса
- `uninstall_service.sh` - скрипт удаления сервиса
- `manage_autostart.sh` - скрипт управления автозапуском

## Установка

### 1. Установка сервиса
```bash
sudo ./install_service.sh
```

**Что делает скрипт:**
- ✅ Автоматически определяет пользователя проекта
- ✅ Автоматически определяет группу проекта
- ✅ Автоматически определяет путь к проекту
- ✅ Создает правильный файл сервиса с актуальными путями
- ✅ Включает автозапуск при перезагрузке

### 2. Запуск сервиса
```bash
sudo systemctl start veppstatus
```

### 3. Автозапуск при перезагрузке
Автозапуск **автоматически включается** при установке сервиса. Сервис будет запускаться при каждой перезагрузке системы.

#### Проверка автозапуска:
```bash
sudo ./manage_autostart.sh check
```

#### Управление автозапуском:
```bash
# Включить автозапуск
sudo ./manage_autostart.sh enable

# Отключить автозапуск
sudo ./manage_autostart.sh disable

# Проверить статус
sudo ./manage_autostart.sh check

# Полная информация
sudo ./manage_autostart.sh info
```

## Управление сервисом

### Основные команды
```bash
# Запустить сервис
sudo systemctl start veppstatus

# Остановить сервис
sudo systemctl stop veppstatus

# Перезапустить сервис
sudo systemctl restart veppstatus

# Статус сервиса
sudo systemctl status veppstatus

# Включить автозапуск
sudo systemctl enable veppstatus

# Отключить автозапуск
sudo systemctl disable veppstatus
```

### Просмотр логов
```bash
# Просмотр логов в реальном времени
sudo journalctl -u veppstatus -f

# Просмотр последних логов
sudo journalctl -u veppstatus -n 50

# Просмотр логов за сегодня
sudo journalctl -u veppstatus --since today
```

## Удаление сервиса
```bash
sudo ./uninstall_service.sh
```

## Особенности

### Автоматическое определение
- **Пользователь**: Определяется как владелец директории проекта
- **Группа**: Определяется как группа директории проекта
- **Пути**: Определяются автоматически относительно расположения скриптов
- **Виртуальное окружение**: Автоматически находится в `veppstatus_env/`

### Автоматический перезапуск
- Сервис автоматически перезапускается при сбоях
- Интервал перезапуска: 10 секунд
- Таймаут остановки: 30 секунд

### Безопасность
- Запуск от имени владельца проекта
- Ограничения на файловые дескрипторы и процессы
- Защита системных файлов
- Приватные временные файлы

### Ресурсы
- Django сервер: http://0.0.0.0:8001
- Сервер сбора данных: tcp://127.0.0.1:4242
- Логи: systemd journal

## Устранение неполадок

### Проверка статуса
```bash
sudo systemctl status veppstatus
```

### Проверка логов
```bash
sudo journalctl -u veppstatus -n 100
```

### Проверка портов
```bash
netstat -tulpn | grep :8001
netstat -tulpn | grep :4242
```

### Ручной запуск для отладки
```bash
./start_veppstatus.sh
```

- Python 3.x
